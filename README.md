# ЭХО — мессенджер СЛОВОПАДА

Отдельное приложение для общения: личные чаты, комнаты и друзья. Вход и данные общие с игрой СЛОВОПАД: тот же ник и пароль.

▶ [Открыть ЭХО](https://felykxzy.github.io/slovopad-echo/) · [Играть в СЛОВОПАД](https://felykxzy.github.io/slovopad.game/)

## Что умеет сейчас
- Экран загрузки и вход (ник и пароль, как в игре)
- Вход по QR-коду из игры: ЭХО показывает код, телефон с игрой сканирует его и вводит число с экрана
- Личные чаты с друзьями, непрочитанные сообщения, статус «в сети», «печатает…» и отметка «прочитано»
- Сообщения: ответ на сообщение, правка и удаление, реакции, фото, стикеры, подсветка @ника
- Меню сообщения: долгое нажатие на любое место сообщения (и на фото), короткое нажатие по фото открывает его на весь экран
- Комнаты: читать и писать, создавать свои, приглашать друзей, закреплённое сообщение и описание комнаты
- Звонки (до 4 человек): голос, видео, показ экрана, выбор камеры; звонок другу из чата, входящий звонок с плашкой «Ответить»
- Друзья: добавить по нику или коду SP-…, принять или отклонить запрос
- Реклама игры на главном экране

## Установить на телефон
Открой ссылку выше. Android: меню браузера → «Установить приложение». iPhone: «Поделиться» → «На экран «Домой»».

## Файл для iPhone
Файл `Echo-….ipa` появляется на странице [релизов](https://github.com/Felykxzy/slovopad-echo/releases/latest) после сборки. Ставится через Sideloadly так же, как игра. Инструкция: `ios-app/README.md` (в игре она тоже есть).
