# ЭХО — мессенджер СЛОВОПАДА

Отдельное приложение для общения: личные чаты, комнаты и друзья. Вход и данные общие с игрой СЛОВОПАД: тот же ник и пароль.

▶ [Открыть ЭХО](https://felykxzy.github.io/slovopad-echo/) · [Играть в СЛОВОПАД](https://felykxzy.github.io/slovopad.game/)

## Что умеет сейчас
- Экран загрузки и вход (ник и пароль, как в игре)
- Личные чаты с друзьями, непрочитанные сообщения, статус «в сети»
- Комнаты: читать и писать
- Друзья: добавить по нику или коду SP-…, принять или отклонить запрос
- Реклама игры на главном экране

## Установить на телефон
Открой ссылку выше. Android: меню браузера → «Установить приложение». iPhone: «Поделиться» → «На экран «Домой»».
