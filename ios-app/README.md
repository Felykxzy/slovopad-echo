# ЭХО для iPhone и iPad

Оболочка, которая открывает ЭХО на экране телефона. Файл `.ipa` собирает GitHub (см. релизы). Ставится через Sideloadly:

1. Скачай `Echo-…ipa` со страницы релизов на компьютер.
2. Подключи iPhone кабелем и нажми «Доверять».
3. В Sideloadly перетащи `.ipa`, выбери iPhone, впиши Apple ID, нажми «Start».
4. На iPhone: «Настройки» → «Основные» → «VPN и управление устройством» → доверяй своему Apple ID.
5. Если нужен режим разработчика: «Настройки» → «Конфиденциальность и безопасность» → «Режим разработчика».

Бесплатный Apple ID держит подпись 7 дней, потом нужно снова нажать «Start» в Sideloadly (данные сохраняются).
